
To set up an automated update of `requirements.txt` using `pipreqs` on every commit, follow the steps below.

---

## **1. Create the pre‑commit hook**

Open the pre‑commit hook file in your local repository:

```
nano .git/hooks/pre-commit
```

Add the following script:

```bash
#!/bin/bash

echo "Updating requirements.txt using pip freeze..."
pip freeze > requirements.txt

git add requirements.txt
echo "requirements.txt has been updated and staged for commit."
```

Save the file and exit the editor.

Make the hook executable:

```
chmod +x .git/hooks/pre-commit
```

---

## **2. Result**

From now on, every time you create a commit, the pre‑commit hook will automatically:

- stage the updated file
- include it in your commit

This ensures your dependency list stays up‑to‑date with the imports used in your project.
