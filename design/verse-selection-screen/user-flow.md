# User Flow

1. User opens the Verse Selection screen
2. User sees empty selections for Book, Chapter, Verse, and Depth. Only the Book selection has options
3. User selects a Book, causing the Chapter selection to get populated with options. If user selects a different book, then the Chapter options change.
4. User selects a Chapter, causing the Verse selection to get populated with options. If user selects a different book, then the Chapter options change accordingly, the Verse options are cleared, and the Chapter selection is cleared
